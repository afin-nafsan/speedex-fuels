# SpeedEX Website

A modern, responsive website for SpeedEX International Quality Refined Petroleum Products.

## Overview

SpeedEX is a premier specialist in EN590 Diesel 10 PPM supply, authorized by Emarat and Adnoc. This website showcases the company's services, products, and industry expertise.

## Features

- **Responsive Design**: Fully responsive across all devices
- **Modern UI**: Clean, professional design with green theme
- **Product Showcase**: Comprehensive petroleum products listing
- **Blog System**: Dedicated blog pages with industry insights
- **Contact Integration**: Complete contact information and forms
- **Search Functionality**: Site-wide search capability

## Pages

- **Homepage** (`index.html`): Main landing page with carousel, services, and blog preview
- **About** (`about.html`): Company overview and SpeedEX/MyFuel relationship
- **Products** (`products.html`): Complete product catalog
- **Services** (`service.html`): Service offerings and features
- **Blog** (`blog.html`): News and industry updates
- **Contact** (`contact.html`): Contact information and form
- **Testimonials** (`testimonial.html`): Client testimonials
- **Features** (`feature.html`): Company features and advantages

## Technology Stack

- HTML5
- CSS3 (Bootstrap 5)
- JavaScript (jQuery)
- SCSS
- Responsive Design
